# 小芽 Sprout · 像素桌宠

一株待在屏幕右下角的小花，提醒你喝水和起身。

这是独立 Windows 桌面程序：透明、置顶、无任务栏大窗口。主窗口仅 184 × 218 个逻辑像素。设置与商店按需打开，不保留原来的网页待办面板。

## 怎么用

1. 启动 `Sprout-1.0.0-Windows.exe`，首次设置喝水与起身间隔（1–180 分钟，默认 30 / 50）。
2. 先在现实中喝口水，再把鼠标放到小花上：光标变成浇水壶，左键点击浇水。低头的小花会抬头恢复精神。
3. 每浇水 3 次，旁边出现 5 枚金币。点击金币收进钱包。
4. 鼠标移入小花，顶部出现金币和设置按钮。点击金币打开小商店，兑换花盆、水壶和花种，购买后立即换上。
5. 起身提醒出现时，起来活动一下，回来点击「我已起身」。浇水只确认喝水，两个提醒独立计时。

按住小花上方的 ⠿ 拖动。右键小花或系统托盘图标，可回到右下角、隐藏、打开设置、打开存档目录或退出。关闭设置/商店不会退出桌宠。

每次点击浇水代表一次本人确认的喝水行为，不检测实际饮水。连续点击有 3 秒冷却，避免双击重复计数。每 3 次浇水产生的金币需主动领取。

## 商店

| 分类 | 默认 | 可兑换 |
|---|---|---|
| 花盆 | 陶土盆 | 云朵盆 10、莓果盆 15、星夜盆 20 |
| 浇水壶 | 薄荷壶 | 蜂蜜壶 10、玫瑰壶 15、晴空壶 20 |
| 花种 | 小雏菊 | 郁金香 15、向日葵 20、薰衣草 25 |

已拥有的装扮可以免费切换。水壶改变实际鼠标光标；花盆与花种改变桌宠像素画。所有图形在本地绘制，没有联网素材与广告。

## 本地运行与打包

需要 Node.js 22.12+，Windows x64。

```sh
npm install --no-package-lock
npm start
npm test
npm run check
npm run smoke
npm run dist
```

便携程序生成于 `release/`。无需安装，双击运行。Electron 提供透明置顶窗口和系统托盘；包体包含独立运行环境。

## 数据与提醒

- 所有进度保存在本机用户数据目录下的 `garden.json`。右键托盘 → 打开存档文件夹。
- 主进程统一验证并原子写入设置、金币和装备，多个面板不会独立修改余额。
- 定时依据实际时间，电脑恢复时补发到期提醒，每个周期只通知一次；小花仍保留到期提示。
- 程序退出、关机或休眠期间无法发提醒；重启/唤醒后检查到期状态。没有自动启动或后台服务。
- 系统通知可关闭，桌宠内提醒保留。Windows 专注模式可能屏蔽系统通知；独占全屏程序可能盖住桌宠。
- 「置顶」通过 Electron 的 `setAlwaysOnTop` 实现：[官方文档](https://www.electronjs.org/docs/latest/api/browser-window)。休眠恢复事件：[官方文档](https://www.electronjs.org/docs/latest/api/power-monitor/)。

## 验证

`tests/state.test.cjs` 覆盖首次设置、浇水恢复、金币领取、防重复购买、余额验证、独立计时和存档校验。

`tests/smoke.cjs` 在独立临时存档中启动真实 Electron 窗口，验证原生窗口大小与置顶、点击浇水、光标替换、三类商店兑换、设置保存和文件持久化；不会读取或修改用户的正式存档。
