# 小芽 Sprout · 像素桌宠

一株常驻屏幕右下角的小向日葵，只提醒喝水。窗口很小，设置、商店和报告按需打开。

## 使用

1. 首次启动只需设置喝水间隔（1–180 分钟，默认 30 分钟）。输入框可以直接用鼠标滚轮以 5 分钟为单位调整。
2. 收到提醒后先在现实中喝水，再把鼠标移到小花上。光标会变成当前浇水壶，左键点击一次即可确认。
3. 同一轮提醒浇水后，花朵抬头恢复，直到下一次提醒前不能重复浇水。提示会明确显示“这次已经浇过了”。
4. 每浇水 3 次会出现 5 枚待领取金币。点击金币后，可在商店兑换花盆、浇水壶和花的品种。

桌宠固定在右下角，顶部的商店和设置按钮始终可见，避免需要追着隐藏控件点击。右键桌宠或系统托盘图标可以打开菜单、查看喝水报告、打开存档目录或退出。

## 喝水报告与数据

每次系统提醒生成一条记录：提醒时间、用户点击浇水的时间，以及两者之间的回应时长。报告页显示提醒次数、已回应次数、平均回应时长和 5 分钟内回应率，并给出当前间隔的简单观察建议。点击浇水只是用户自我确认，程序不会检测真实饮水量，也不会把建议当作医疗结论。

数据保存在本机 Electron 用户数据目录的 `garden.json`，Windows 通常是 `%APPDATA%\\Sprout\\garden.json`。右键托盘 → 打开存档文件夹可以直接打开实际目录。这里保存提醒设置、喝水记录、浇水次数、金币和装扮；没有云端数据库或账号同步。

## 商店

| 分类 | 默认 | 可兑换 |
|---|---|---|
| 花盆 | 陶土盆 | 云朵盆 10、莓果盆 15、星夜盆 20 |
| 浇水壶 | 薄荷壶 | 蜂蜜壶 10、玫瑰壶 15、晴空壶 20 |
| 花种 | 向日葵 | 小雏菊 0、郁金香 15、薰衣草 25 |

已拥有的装扮可以免费切换。所有图形在本地绘制，没有联网素材与广告。

## 本地运行与打包

需要 Node.js 22.12+，Windows x64。

```sh
npm install --no-package-lock
npm run dev
npm start
npm test
npm run check
npm run smoke
npm run dist
```

开发时运行 `npm run dev`：程序启动后会监听 `app/` 下的 HTML、CSS、JS 和像素资源，保存文件后自动刷新桌宠及当前面板，不需要重新下载或重新打包。需要给别人使用时再运行 `npm run dist`，便携程序生成于 `release/`，双击即可运行。

## 提醒边界

程序退出、关机或休眠期间无法发提醒；重启或唤醒后会检查是否到期。系统通知可以在设置中关闭，桌宠内提示仍会保留。Windows 专注模式可能屏蔽系统通知。
